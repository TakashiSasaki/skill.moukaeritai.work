# Schema Sources

The canonical sources for the `DocumentRecord` domain are located in the `specs/` directory:

- **JSON Schema:** `specs/json-schema/document-record.schema.json`
- **RDF Vocabulary:** `specs/vocab/core.ttl`
- **SHACL Shapes:** `specs/shacl/document-record.shacl.ttl`
- **SQL DDL:** `specs/sql/document-record.sqlite.sql`
- **JSON-LD Context:** `specs/mappings/jsonld/document-record.context.jsonld`

If you are working in a downstream bundle, these are available as snapshots in `references/specs/`.
